# Read the evidence

The explorer’s normalized timeline is a navigation layer, not the oracle. A trustworthy conclusion
must remain traceable to the sealed record:

- native Temporal Event History and successful replay;
- raw process, workspace, destination, and effect observations;
- exact source, executable, schema, and manifest hashes;
- independent audit verdicts;
- correction lineage for superseded evidence.

Read the responsibility split literally. Temporal owns durable procedure and redelivery. The
application owns stable identity, authority, replacement, and cancellation policy. The destination
owns conditional effect acceptance. Executor process or provider IDs are observations, never durable
authority.

Finally read the falsifier. The claim must narrow if the unsafe control stops distinguishing, a stale
or canceled owner commits, replacement precedes fencing, process cleanup is unverified, raw evidence
disagrees with the normalized view, or history replay fails. The current evidence remains bounded to
its declared single-host, version, destination, and authentication conditions.
