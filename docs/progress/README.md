# Research progress

This directory holds dated snapshots of the Agent Durability Lab's execution
status. These documents answer “what had been completed or remained open at a
particular point?” without turning the repository's root README into a changing
results log.

The authoritative sources remain:

- [`../findings/`](../findings/) for supported, falsifiable conclusions;
- [`../guarantees.md`](../guarantees.md) for responsibility attribution and
  evidence links;
- [`../research-questions.md`](../research-questions.md) for the investigation
  queue; and
- Beads for live task status and dependencies.

Snapshots are append-only historical summaries. A later snapshot may supersede
their status, but it does not rewrite what was known at the earlier date.
